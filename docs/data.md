# Data

This project uses two primary datasets:

- CPS microdata (.dta) — used to compute demographics and tax features. Place `cps_data.dta` at the project root (or adjust paths in `src/data_loader.py`).
- Zillow state-level housing prices (.csv) — `Data_Files/price_by_state_cleaned.csv`.

Processed output:
- `Data_Files/state_full.csv` (generated by `python -m src.data_loader`).

Notes:
- We forward-fill demographic features monthly between annual observations and interpolate where needed.
- For reproducibility, large raw data files are not tracked in Git; see `.gitignore`.
